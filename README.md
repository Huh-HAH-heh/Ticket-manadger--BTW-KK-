# Ticket Manager

Консольная Service Desk-система на C#, .NET 10, Entity Framework Core и PostgreSQL.

## Реализовано

- Регистрация клиента и вход по логину/паролю.
- Солёный PBKDF2-SHA256-хэш пароля; исходный пароль не сохраняется.
- Первичная настройка первого администратора отдельной командой.
- Роли `Client`, `Operator`, `Admin` с разными доступными действиями.
- Клиент может видеть и искать только собственные заявки и создавать заявки от своего имени.
- Оператор может просматривать/искать заявки, редактировать их и менять статусы.
- Администратор управляет заявками и учётными записями, назначает роли, деактивирует пользователей и смотрит статистику.
- Деактивация пользователя сохраняет историю его заявок.
- Поиск, фильтрация, сортировка и аналитика.

## Настройка подключения

Установите переменную окружения в PowerShell:

```powershell
$env:TICKET_DB_CONNECTION = "Host=localhost;Port=5433;Database=ticket_db;Username=postgres;Password=ВАШ_ПАРОЛЬ"
```

Не сохраняйте настоящий пароль в Git.

## Миграции

Из корня репозитория выполните:

```powershell
dotnet tool install --global dotnet-ef --version 10.0.13
dotnet ef database update --project "Ticket manadger/Ticket manadger.csproj"
```

Установка инструмента нужна только если `dotnet-ef` ещё не установлен. Миграции добавляют поле хэша пароля, логин, email, мягкое удаление, уникальные индексы и исправляют имена двух столбцов согласно коммиту `+context`.

## Создание первого администратора

После применения миграций:

```powershell
dotnet run --project "Ticket manadger/Ticket manadger.csproj" -- --bootstrap-admin
```

Команда создаёт администратора только если действующего администратора ещё нет. Публичная регистрация создаёт только клиентов.

## Запуск

```powershell
dotnet run --project "Ticket manadger/Ticket manadger.csproj"
```

## Ограничения оставшейся модели

В аналитическом контексте также указаны приоритеты заявок, исполнитель (`ExecutorId`), комментарии и журнал истории. Эти сущности и назначение исполнителей пока не реализованы; этот коммит добавляет регистрацию, вход и базовое разграничение прав на существующей модели.
