# Локальная эксплуатация Ticket Manager через Docker

Инструкции по установке, первому запуску, созданию администратора, повседневной работе, остановке и резервному копированию сведены в один документ:

**[docs/OPERATIONS.md](OPERATIONS.md)**

Для обычного запуска используй единственную пользовательскую точку входа из корня репозитория:

```cmd
Start-TicketManager.cmd
```

Этот файл поднимает Docker Compose, при необходимости проводит первичную настройку администратора и запускает консольный клиент.

Эта страница сохранена как ссылка со старого пути документации. Не используй старые раздельные инструкции запуска.
